# Orbit 0.3 — свой островок для Windows 11

Это самостоятельная реализация по функциональному референсу Island. Исходники открыты для изменений. Не использует код, логотипы, платные ресурсы и лицензионные механизмы Island.

## Запуск готовой сборки

1. Распакуйте **весь** архив `Orbit-Windows-x64.zip` в постоянную папку, например `Документы\Orbit`.
2. Запустите `Orbit.exe`. Node.js и установка зависимостей для готовой сборки не нужны. Это сборка для Windows x64, без цифровой подписи издателя.
3. Нажмите островок наверху экрана или значок Orbit в области уведомлений. По умолчанию он раскрывается при наведении без перевода фокуса и сворачивается после ухода курсора. В общем разделе настроек задаются задержки, сквозной режим и правила для выбранных приложений. В настройках можно переключить форму с «Капсула» на «У верхней кромки».
4. Настройки открываются в отдельном окне по кнопке ⚙ или через меню в трее. В разделе «Общее» есть переключатель аппаратного ускорения. Изменение применяется при следующем запуске Orbit. В них можно изменить цвет, тему, персонажа, размер, прозрачность, монитор, положение, отступ и клавиши. Автозапуск выключен по умолчанию.
5. Не переносите только `Orbit.exe`: ему нужны остальные файлы из архива.

Закрыть приложение можно через значок в области уведомлений → «Выход» или в настройках Orbit.

## Spotify, ChatGPT и Codex

Кнопки запуска, без API и без ключей. Spotify запускается через зарегистрированный протокол `spotify:`; если приложение не установлено, предусмотрена веб-ссылка. ChatGPT и Codex по умолчанию открываются в браузере. Чтобы открывать установленное приложение, откройте настройки, нажмите `…` напротив нужной кнопки и выберите его `.exe` или ярлык `.lnk`. Поддерживаются также HTTP(S)-ссылки, `steam:` и интернет-ярлыки `.url`.

Кнопки можно добавлять, удалять, переименовывать, назначать им символ, группу и глобальное сочетание. Одинаковое имя группы объединяет кнопки под заголовком.

## Что реализовано

- Компактная панель поверх окон, раскрытие по клику и наведению, сворачивание при уходе курсора, автоскрытие за край и выбор монитора. Возможность скрывать панель при полноэкранном окне.
- Системный плеер Windows: название трека, исполнитель, обложка, пауза, предыдущий/следующий трек, прогресс. Обложка доступна, когда плеер передаёт её в медиасессию Windows. При запуске трека Orbit автоматически ищет слова по названию и исполнителю в LRCLIB. При наличии временных меток активная строка подсвечивается и прокручивается по позиции воспроизведения. Открытый текст обновляется при смене трека. Без меток показывается обычный текст. Не требует Spotify API. Выбирает играющую медиасессию Windows. Источник можно выбрать в плеере. Spotify, Яндекс Музыка и вкладки браузера поддерживаются, когда публикуют медиасессию. Браузерный источник отображается под именем браузера.
- Ползунок громкости, отключение звука и выбор устройства вывода Windows. Колесо мыши на свёрнутой панели также меняет громкость. Эквалайзер сохраняет профиль Orbit-EQ.txt. Для обработки аудио включите Equalizer APO для нужного устройства и добавьте скопированную строку Include в его config.txt.
- История буфера текста и изображений: поиск, закрепление, удаление, очистка незакреплённых записей, копирование и попытка вставить в предыдущее активное окно. Включается отдельно в настройках. До 60 незакреплённых записей; большие изображения и тексты пропускаются. Известные флаги приватности буфера учитываются; точное определение секретного текста не гарантируется.
- При перетаскивании файлов или ярлыков на островок появляются цели «На полку», «В лаунчер» и «В чат». Последняя копирует пути и открывает ChatGPT, где файл можно прикрепить вручную. Полка файлов: добавление диалогом и перетаскиванием, открытие, показ в проводнике, перетаскивание наружу за значок. Хранятся ссылки на оригинальные файлы; удаление с полки не удаляет файл.
- Несколько текстовых заметок с папками и автосохранением. Обычный текст / Markdown, без визуального форматирования.
- Таймер: пресеты, своё время, пауза, продолжение, отображение в пилюле. Напоминания на дату/время, разовые и ежедневные, со звуком и карточкой. Они сохраняются между запусками. Напоминание можно отложить на 10 минут, а завершённый таймер запустить заново. Пока приложение закрыто, будильник не работает; просроченные напоминания показываются после запуска.
- Поиск по настроенным ярлыкам, безопасный арифметический калькулятор, веб-поиск, команды `таймер 10 мин`, `напомни через 20 мин позвонить`, переходы в системные параметры.
- Скриншот выбранного монитора: обрезка, перо, рамка, стрелка, подпись, непрозрачное скрытие области, отмена, PNG и буфер. Для нескольких мониторов выберите нужный в настройках.
- OCR установленными распознавателями Windows, QR-код с экрана, HEX-пипетка и история цветов. В режиме OCR/QR сначала выделите область; результат копируется локально. Установка дополнительных языков распознавания — через Windows.
- Запись выбранного монитора с системным звуком либо без звука. MP4 при наличии подходящего кодека Chromium, иначе WebM; фактический формат указан во время записи. Во время записи не закрывайте приложение. Запись хранится в памяти до остановки — для длинных сессий лучше отдельный рекордер.
- Голосовой ввод через штатный интерфейс Windows `Win+H`, без встроенной нейросети и ключей API.
- Регистр, смена раскладки, транслитерация, форматирование JSON, Base64 с Unicode и URL-кодирование.
- Температура и значок погоды в свёрнутом островке. Город меняется на вкладке «Погода», по названию города в левой карточке. Там же есть прогноз по часам и на неделю, ветер, влажность, давление, восход и закат, осадки и УФ-индекс. По умолчанию используется Москва. Прогноз обновляется через Open-Meteo при запуске и каждые 15 минут.
- Вкладка «Управление» показывает сеть, Bluetooth, тёмную тему и Happ. Карточки сети и Bluetooth открывают параметры Windows. Кнопка Happ переключает подключение в клиенте, правый клик по значку в шапке проверяет внешний IP и страну через IPinfo. Здесь же есть блокировка, сон, перезагрузка и выключение.
- Локальный экспорт данных в JSON, открытие папки данных.

## Клавиши

- `Alt+Space` — открыть поиск (можно изменить).
- `Ctrl+Alt+I` — открыть/свернуть панель.
- `Ctrl+Alt+V` — история буфера.
- `Ctrl+Alt+S` — скриншот.
- `Ctrl+Alt+O` — OCR.
- `Ctrl+Alt+Q` — QR с экрана.
- `Ctrl+Alt+C` — пипетка.
- `Ctrl+Alt+R` — начать/остановить запись экрана.
- `Ctrl+Alt+Shift+V` — вставить текст без форматирования.
- `Escape` — свернуть; в захвате экрана — закрыть.

Если сочетание занято другой программой, Orbit сообщает об этом. Значок в области уведомлений позволяет открыть Orbit независимо от горячих клавиш.

## Отличия от полного Island

В этой версии **нет** встроенного AI-чата и запросов к моделям, работы с документами через AI, командных разрешений агентов, зеркалирования уведомлений других приложений, статусов загрузок браузера/Steam, OBS, микрофона/камеры, настоящего аудиоспектра, 25 персонажей оригинала, глобального поиска по установленным приложениям и диску, конвертера валют, группировки ярлыков перетаскиванием, редактирования напоминаний и недельных расписаний, GIF, загрузки скриншотов на хостинг и автообновлений. В настройках доступны режимы музыкальной капсулы: обложка, название с прогрессом, мини-плеер и текущая строка текста. На главной можно скрывать отдельные модули и вкладки. Пиксельный призрак реагирует на музыку, события, файлы и бездействие. Мопс по умолчанию моргает, покачивается, реагирует на наведение и подпрыгивает при воспроизведении. При воспроизведении в свёрнутом островке видны обложка и полоски эквалайзера. Из обложки берётся цвет интерфейса, а при смене раскладки на короткое время появляется код языка. У сферы есть декоративная пульсация, у глаз — слежение за курсором внутри панели. Настройка Windows уменьшения движения отключает анимации. Это не измерение звука.

ChatGPT и Codex намеренно оставлены кнопками запуска согласно пожеланию пользователя. Скриншоты, запись, вставка и медиасессии используют Windows/Chromium и могут зависеть от прав, кодеков и политики компьютера. В окна с повышенными правами вставка может не сработать; запись при этом всё равно можно скопировать обычным способом. Эксклюзивные полноэкранные игры могут не показывать панель. DRM-контент может не захватываться.

## Данные и сеть

Настройки: `%APPDATA%\orbit-island\settings.json`; заметки, таймеры, полка и история — `state.json` рядом. Папку можно открыть кнопкой «Папка данных». Данные не зашифрованы. Экспорт включает историю буфера и пути к файлам — храните резервную копию соответственно её содержимому. Никаких аналитических запросов и автообновлений нет. Сеть используется при открытии ваших ссылок, по запросу внешнего IP в IPinfo, для обновления погоды по выбранному городу (geocoding-api.open-meteo.com, api.open-meteo.com) и при автоматическом поиске текста трека по названию и исполнителю на lrclib.net.

Нативный помощник запускает включённый скрипт PowerShell без отдельного окна; он получает медиасессию, раскладку, батарею, активное окно, выполняет OCR и медиакоманды. Если политика организации запрещает PowerShell, эти функции недоступны.

## Проверка этой сборки

Проверены JavaScript-синтаксис, арифметика и преобразования, интерфейс в Chromium с тестовым мостом (запуск, настройки, поиск буфера, полка, заметки, таймер, команды), редактор захвата (обрезка/отмена/пипетка/вывод OCR и QR) и сборка Windows x64. Тесты моста в браузере не проверяют реальные Windows API. На Windows 11 проверены запуск готового Orbit.exe, раскрытие и сворачивание, анимации мопса, чтение системного статуса, получение и показ обложки активного трека Spotify через WinRT и поиск текста тестового трека в LRCLIB. Вставка, голосовой ввод, OCR, запись, управление воспроизведением и автозапуск пока не проверены вручную. Сборка экспериментальная.

## Разработка

Нужны Node.js 22+ и npm. Следующие команды предназначены для полного дерева исходников. Распакованная сборка в этой папке уже содержит среду Electron и запускается через Orbit.exe.

```sh
npm install
npm start
npm run check
npm run build:win
```

Готовая сборка появляется в `dist/Orbit-win32-x64`. При кросс-сборке в среде с прокси используйте `ELECTRON_GET_USE_PROXY=1`.

- `main.js` — окно, IPC, данные, таймеры, буфер, захват и системные функции.
- `native.js`, `native/windows.ps1` — Windows-мост.
- `index.html`, `style.css`, `renderer.js` — панель и настройки.
- `capture.html`, `capture.js` — редактор захвата.
- `core.js` — калькулятор и текстовые преобразования.

Исходный код Orbit предоставляется по лицензии MIT. Зависимости имеют собственные лицензии, включённые в дистрибутив. Референс: https://islandapp.pro/ (ознакомление 11.11.2026).
